Security Recommendations

{% if results.xss %}
Cross-Site Scripting (XSS)
  • Implement proper input sanitization and output encoding.
  • Use frameworks that automatically escape HTML output.
  • Enable Content Security Policy (CSP) headers.
  • Validate and filter user-generated content.
{% endif %} {% if results.html %}
HTML Injection
  • Sanitize all HTML-sensitive characters before rendering.
  • Apply strict server-side input validation.
  • Avoid directly embedding user input into HTML responses.
{% endif %} {% if results.ssrf %}
Server-Side Request Forgery (SSRF)
  • Restrict outbound server requests using allowlists.
  • Block requests to localhost and internal IP ranges.
  • Disable access to cloud metadata endpoints.
  • Validate and sanitize all user-supplied URLs.
{% endif %} {% if results.csrf %}
Cross-Site Request Forgery (CSRF)
  • Implement anti-CSRF tokens for all sensitive forms.
  • Use SameSite cookie attributes.
  • Require re-authentication for critical actions.
  • Validate Origin and Referer headers.
{% endif %} {% if results.sqlmap and results.sqlmap.vulnerable %}
SQL Injection
  • Use parameterized queries or prepared statements.
  • Avoid dynamic SQL query construction.
  • Apply strict server-side validation.
  • Use ORM frameworks where possible.
{% endif %} {% if results.xxe %}
XML External Entity (XXE)
  • Disable external entity processing in XML parsers.
  • Use secure XML libraries and parser configurations.
  • Validate uploaded XML content.
  • Restrict file system access permissions.
{% endif %}
